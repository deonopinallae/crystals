# Crystals

Современный лендинг для интернет-магазина кристаллов и минералов с акцентом на эстетику и пользовательский опыт.

## Описание

Одностраничный веб-сайт, представляющий коллекцию кристаллов и минералов. Сайт построен на принципах Feature-Sliced Design.

## Основные возможности

- **Каталог кристаллов** — отображение популярных типов кристаллов (Tower, Pyramid и др.) с ценами и изображениями
- **Выбор по намерениям** — навигация по кристаллам в зависимости от желаемой энергии (Heal, Protect, Love, Balance, Calm, Create, Manifest)
- **Отзывы клиентов** — интерактивная секция с отзывами покупателей
- **Crystal Club** — информация о программе лояльности
- **Адаптивный дизайн** — полная поддержка мобильных устройств и планшетов
- **Интерактивные элементы** — карусели, слайдеры и анимированные компоненты
